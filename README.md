# TI_Saude

## Saúde: 
- Diagnostico -> Volumes de Dados (Algoritmo de aprendizado de Maquinas)
- Monitoramento ou Sensores a Atuação -> Automação 
- Predição e Previsão -> Reconhecimento de padrões (Volume de dados -> Algoritmos de Mineração)

### Sistemas de Apoio a Decisão: 
- Sistema que indica um caminho por meio de uma lista de melhores escolhas, com base em uma banco de conhecimentos científicos
e informações de dados dinâmicos e específicos. 

### Sistemas de Recomendação: 
- Sistema que indica uma escolha com base nas preferências ou histórico do usuário.

## Sistemas Utilizados:
### Redes Neurais -> Aprendizagem -> Reconhecimentos de Padrões
- RNA P.
- ML
- MD
